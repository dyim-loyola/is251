# Module 11: Cloud Computing

## ☁️ Overview

This module introduces **cloud computing** as the foundation of modern information systems. Students will learn the basics of cloud models and services, then practice with **hands-on AWS labs**. The focus is on *understanding core ideas* and *navigating real cloud tools*, not just theory.

---

## 🎯 Learning Objectives

By the end of this module, students will be able to:

1. **Define** cloud computing in simple terms.
2. **Explain** elasticity, cost efficiency, and accessibility in business terms.
3. **Differentiate** between the three main service models: IaaS, PaaS, SaaS.
4. **Identify** key AWS services and their purposes.
5. **Launch** a basic EC2 web server and configure a load balancer.

---

## 📌 Key Concepts

- **Cloud Computing** – Renting computing resources over the internet.
- **Elasticity** – Instantly scale resources up or down.
- **Cost Efficiency** – Pay-as-you-go vs. buying your own servers.
- **Accessibility** – Access from anywhere, on any device.
- **Service Models** – IaaS, PaaS, SaaS.
